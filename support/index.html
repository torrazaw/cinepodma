FAQ
ရပါသည် — Guest mode ဖြင့် ရေးနိုင်သော်လည်း Cloud save မရပါ။ PDF download ဆွဲနိုင်ပါသည်။ Cloud save + Profile အတွက် account ဖွင့်ရန် လိုအပ်သည်။
Login မဝင်ထားပါက browser localStorage တွင် သိမ်းသည်။ Login ဝင်ပြီး save နှိပ်ပါက Firebase Firestore cloud တွင် သိမ်းသည် — ဘယ် device မှမဆို access ရနိုင်သည်။
Write page တွင် Sign in → "Password မေ့သွားပြီလား?" ကို နှိပ်ပါ — email ထည့်ရင် reset link ပို့ပေးမည်။
Screenplay type အတွက်သာ PDF export ရနိုင်သည်။ Cover → Logline → Synopsis → Treatment → Screenplay pages အစဉ်လိုက် PDF ဖြစ်မည်။ Watermark option ပါသည်။ Story type များကို CinePodma ထဲမှသာ ဖတ်ရနိုင်ပါသည်။
Public ဆိုရင် Library တွင် ပေါ်မည်၊ မည်သူမဆို ဖတ်နိုင်သည်။ Private ဆိုရင် ကိုယ်တိုင်သာ မြင်နိုင်သည်။ Profile menu မှ ခလုတ်နှိပ်ကာ ပြောင်းနိုင်သည်။
Instagram Like ကဲ့သို့ — တစ်ဦး၏ profile ကို ကြိုက်ပါက 👏 Clap နှိပ်နိုင်သည်။ Clappers count သည် profile ၏ popularity ကို ဖော်ပြသည်။
