About

CinePodma သည် မြန်မာ screenplay ရေးသားသူများအတွက် ဖန်တီးလုပ်ဆောင်ထားသော professional script editor ဖြစ်သည်။

Industry standard format — INT/EXT မြင်ကွင်း၊ ဒိုင်ယာလော့ဂ်၊ action line များကို မြန်မာဘာသာဖြင့် ရေးသားနိုင်သည်။

Support

ရိုက်ပြီးသား သို့ အဆင့်သင့်ဖြစ်သော script ဖိုင် ကို တင်ပါ။ CinePodma က သင့် ဇာတ်ညွှန်းကို web ပေါ်တွင် လူအများ ဖတ်ရှုနိုင်အောင် ပြသပေးမည့် ပုံစံဖြစ်သည် (ဥပမာ — PDF၊ စာသားဖိုင် စသည်)။

ဇာတ်ညွှန်း ဖိုင် တင်ရန်

အောက်ပါ အကွက်တွင် ဖိုင်ရွေးပါ။ နောက်ပိုင်းတွင် ဆာဗာသို့ သိမ်းပြီး ဖတ်ရှုစာမျက်နှာနှင့် ချိတ်ဆက်မည်ဖြစ်သည်။ လက်ရှိ UI အမြက်သက်သာဖြစ်သည်။

လက်ရှိတွင် ဖိုင်ကို ဆာဗာသို့ မသိမ်းသေးပါ — ရွေးထားသော ဖိုင်အမည်ကို အောက်တွင်ပြသသည်က UI အတွက်သာဖြစ်သည်။
